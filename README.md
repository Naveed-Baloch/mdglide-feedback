# MD Glide support & feedback

MD Glide is a Markdown viewer and editor for Chrome. Drag a local `.md` file into a Chrome tab, read and edit offline, and export HTML or PDF.

This public repository contains support documentation, bug reports, and feature requests. The extension's source code stays in a separate private repository.

## Get help

- [Report a bug](https://github.com/Naveed-Baloch/mdglide-feedback/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/Naveed-Baloch/mdglide-feedback/issues/new?template=feature_request.yml)
- [Browse existing reports](https://github.com/Naveed-Baloch/mdglide-feedback/issues)
- [Read the privacy policy](https://baloch.dev/apps/mdglide/privacy.html)

A GitHub account is required to post. Search existing reports before creating a new one. All issues, comments, and attachments are public: remove private text, file paths, credentials, and personal information. Use a small, sanitized Markdown example to demonstrate a problem.

## Open a local Markdown file

1. Open Chrome's Extensions page, find MD Glide, and choose **Details**.
2. Enable **Allow access to file URLs**.
3. Drag a `.md` file from your computer into a Chrome tab.
4. Choose Preview, Split, or Edit. Save locally through the file picker.

Local reading and editing work offline. Remote images and resources referenced by documents or custom CSS can still require internet access. On GitHub, open a Markdown file's **Raw** view before using the extension to render it.

## Report a useful bug

Include your Chrome version, MD Glide version, operating system, steps to reproduce, and expected versus actual behavior. Attach only sanitized screenshots or sample Markdown. Do not post confidential files or security-sensitive details here.

## Requests and status

Feature requests should describe the problem you want to solve and how a proposed change would help. Reports are reviewed by the maintainer; submission does not guarantee implementation or a response date.

## Privacy

The extension processes documents on your device and does not upload them to the developer. Information you voluntarily post in this repository is sent to GitHub and is public. See the [full privacy policy](https://baloch.dev/apps/mdglide/privacy.html) before sharing support materials.
